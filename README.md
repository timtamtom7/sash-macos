# Sash

A window manager for macOS with snapping.

## What it does

- Window snapping
- history
- display profiles
- automation

## Targets

- macOS menu bar

## Structure

Key types:

- ``WindowManager``
- ``WindowHistoryManager``
- ``SnapBorderView``
- ``SashPopoverView``
- ``AutomationManager``
- ``DisplayProfile``
- ``CollaborationService``

The snapping borders and window history are the core of it.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.

Xcode projects here were generated with XcodeGen (`project.yml`) unless noted; open the `.xcodeproj` directly.
